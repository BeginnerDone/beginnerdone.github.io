国际化 ​

@wlink/locale 是一个纯数据包，专门提供国际化语言包数据，不包含任何处理逻辑。国际化的处理逻辑由 @wlink/config-provider 包提供。通过这两个模块的配合，您可以轻松地在应用中实现语言切换功能，使您的应用支持多种语言。

基本配置 ​

配置默认语言 ​

在应用入口文件中配置默认语言：

typescript
import { createApp } from 'vue';
import App from './App.vue';
import { ConfigProvider } from '@wlink/config-provider';
import { zhCN } from '@wlink/locale';

const app = createApp(App);

// 设置默认语言为中文
ConfigProvider.config({
  locale: zhCN
})

app.mount('#app');

切换语言 ​

您可以在应用的任何地方切换语言：

typescript
import { ConfigProvider } from '@wlink/config-provider';
import { enUS } from '@wlink/locale';

// 切换到英文
ConfigProvider.setLocale(enUS);

语言切换示例 ​

下面是一个完整的语言切换示例：

vue
<template>
  <div>
    <div class="language-switcher">
      <a-button @click="switchToZhCN" :type="isZhCN ? 'primary' : 'default'">简体中文</a-button>
      <a-button @click="switchToZhTW" :type="isZhTW ? 'primary' : 'default'">繁體中文</a-button>
      <a-button @click="switchToEnUS" :type="isEnUS ? 'primary' : 'default'">English</a-button>
    </div>
    
    <h2>{{ ConfigProvider.t('common.tip') }}</h2>
    <p>{{ ConfigProvider.t('demo.dialogContent') }}</p>
  </div>
</template>

<script setup lang="ts">
import { computed } from 'vue';
import { ConfigProvider } from '@wlink/config-provider';
import { zhCN, zhTW, enUS } from '@wlink/locale';

// 判断当前语言
const isZhCN = computed(() => ConfigProvider.currentLocale === zhCN);
const isZhTW = computed(() => ConfigProvider.currentLocale === zhTW);
const isEnUS = computed(() => ConfigProvider.currentLocale === enUS);

// 切换到简体中文
function switchToZhCN() {
  ConfigProvider.setLocale(zhCN);
}

// 切换到繁体中文
function switchToZhTW() {
  ConfigProvider.setLocale(zhTW);
}

// 切换到英文
function switchToEnUS() {
  ConfigProvider.setLocale(enUS);
}
</script>

自定义语言包 ​

您可以使用 mergeLocale 工具函数来创建自定义语言包，扩展或覆盖默认的语言配置：

typescript
import { zhCN } from '@wlink/locale';
import type { Language } from '@wlink/locale/types';
import { ConfigProvider, mergeLocale } from '@wlink/config-provider';

// 创建自定义中文语言包
const customZhCN: Language = mergeLocale(zhCN, {
  // 添加或覆盖翻译
  custom: {
    hello: '你好',
    welcome: '欢迎使用我们的应用'
  },
  // 覆盖现有翻译
  common: {
    ok: '好的'
  }
});

// 使用自定义语言包
ConfigProvider.setLocale(customZhCN);

扩展现有语言包 ​

您也可以为应用添加特定的国际化内容：

typescript
import { zhCN, mergeLocale } from '@wlink/locale';

// 为应用添加特定的国际化内容
const appLocale = mergeLocale(zhCN, {
  app: {
    title: '我的应用',
    menu: {
      home: '首页',
      about: '关于'
    }
  }
});

语言包结构 ​

内置语言包采用扁平化结构，便于扩展和维护：

typescript
// 语言包结构
const locale = {
  // 通用文本
  common: {
    confirm: '确认',
    cancel: '取消',
    ok: '确定',
    close: '关闭',
    save: '保存',
    delete: '删除',
    edit: '编辑',
    add: '添加',
    search: '搜索',
    reset: '重置',
    more: '更多',
    loading: '加载中...',
    noData: '暂无数据',
    success: '成功',
    failed: '失败',
    error: '错误',
    warning: '警告',
    info: '信息',
    tip: '提示'
  },
  
  // 组件国际化 - 使用扁平化结构，便于扩展
  antd: {
    dialog: {
      okText: '确定',
      cancelText: '取消',
      justOkText: '知道了',
      title: '提示'
    }
    // 其他 antd 组件...
  },
  
  // 支持任意扩展
  [key: string]: any
};

内置语言包 ​

@wlink/locale 目前提供以下内置语言包：

  • zhCN: 简体中文语言包
  • zhTW: 繁体中文语言包
  • enUS: 英文语言包

您可以根据需要导入并使用这些语言包：

typescript
import { zhCN, zhTW, enUS } from '@wlink/locale';
import type { Language } from '@wlink/locale/types';

console.log(zhCN.common.ok); // '确定'
console.log(zhTW.common.ok); // '確定'
console.log(enUS.common.ok); // 'OK'

与 config-provider 配合使用 ​

实际的国际化功能需要配合 @wlink/config-provider 使用：

typescript
// 在组件中使用
import { ConfigProvider,currentLocale } from '@wlink/config-provider';
import { enUS } from '@wlink/locale';

// 切换语言
ConfigProvider.setLocale(enUS);

// 获取当前语言包
const currentLocale = currentLocale.value;
