介绍 ​

@wlink/element-ui 是基于 element-plus 的二次封装，主要是为了解决 element-plus 组件库的一些问题，以及提供更加易用的组件。

注意

@wlink/element-ui 依赖 element-plus，所以在使用 @wlink/element-ui 之前，需要先安装 element-plus。

快速开始 ​

本文介绍如何在项目中使用 @wlink/element-ui

安装 ​

使用 npm 包管理安装

shell
 npm install @wlink/element-ui --save

全局全部注册 ​

typescript
// main.ts
import { createApp } from "vue";
import WlinkUI from "@wlink/element-ui";
import "@wlink/element-ui/theme/index.css";
// 或者 import "@wlink/element-ui/theme/src/index.less";
import App from "./App.vue";

const app = createApp(App);

app.use(WlinkUI);
app.mount("#app");

全局部分注册 ​

typescript
// main.ts
import { createApp } from "vue";
import { WPrice } from "@wlink/element-ui";
import "@wlink/element-ui/theme/index.css";
// 或者 import "@wlink/element-ui/theme/src/index.less";
import App from "./App.vue";

const app = createApp(App);

app.use(WPrice);
app.mount("#app");

按需导入组件 ​

typescript
import { WPrice } from "@wlink/element-ui";
import "@wlink/element-ui/theme/src/price.less";
export default defineComponent({
    components: { WPrice },
    setup() {}
});

全局注册时设置注册前缀 ​

typescript
import { WPrice } from "@wlink/element-ui";
app.use(WPrice,{
    { prefixComponent: "D" }
});

则替换前缀使用

html
<d-price></d-price>
