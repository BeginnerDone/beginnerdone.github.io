WCascader 级联选择器 ​

级联选择器，用于多级数据的选择，支持静态数据和动态加载。

基础用法 ​

基础用法
使用静态的 options 数据，适用于数据量较小且固定的场景
<template>
    <div class="demo-section">
        <h3>基础用法</h3>
        <p>使用静态的 options 数据，适用于数据量较小且固定的场景</p>
        <WCascader
            v-model:value="staticValue"
            :options="staticOptions"
            placeholder="请选择（静态 options）"
            allow-clear
            :field-names="fieldNames"
        />
        <div class="result">
            <p>选中的值: {{ staticValue }}</p>
        </div>
    </div>
</template>

<script setup>
import { ref } from "vue";
const fieldNames = {
    label: "label",
    value: "value",
    children: "children"
};

// 静态数据 options 用法
const staticValue = ref([]);
const staticOptions = ref([
    {
        label: "水果",
        value: "fruit",
        children: [
            { label: "苹果", value: "apple" },
            { label: "香蕉", value: "banana" },
            { label: "橙子", value: "orange" }
        ]
    },
    {
        label: "蔬菜",
        value: "vegetable",
        children: [
            { label: "西红柿", value: "tomato" },
            { label: "黄瓜", value: "cucumber" },
            { label: "胡萝卜", value: "carrot" }
        ]
    },
    {
        label: "肉类",
        value: "meat",
        children: [
            { label: "猪肉", value: "pork" },
            { label: "牛肉", value: "beef" },
            { label: "鸡肉", value: "chicken" }
        ]
    }
]);
</script>

多级联动 ​

多级联动
每一级使用不同的 URL，适用于标准的多级联动场景，如行政区域选择
<template>
    <div class="demo-section">
        <h3>多级联动（行政区域）</h3>
        <p>每一级使用不同的 URL，适用于标准的多级联动场景，如行政区域选择</p>
        <WCascader
            v-model:value="regionValue"
            :levels="regionLevels"
            placeholder="请选择行政区域"
            isLoadData
            allow-clear
        />
        <div class="result">
            <p>选中的值: {{ regionValue }}</p>
            <p>选中的标签: {{ regionLabels }}</p>
        </div>
    </div>
</template>

<script setup>
import { ref } from "vue";

// 多级 levels（行政区域）
const regionValue = ref([]);
const regionLabels = ref([]);
const regionLevels = ref([
    {
        url: "/api/region/provinces",
        method: "get"
    },
    {
        url: "/api/region/cities",
        method: "get"
    },
    {
        url: "/api/region/districts",
        method: "get"
    }
]);
</script>

树结构数据 ​

树结构数据
只有一项 levels 配置，一次性获取完整的树结构数据
<template>
    <div class="demo-section">
        <h3>树结构数据</h3>
        <p>只有一项 levels 配置，一次性获取完整的树结构数据</p>
        <WCascader
            v-model:value="treeValue"
            :levels="treeLevel"
            placeholder="请选择部门"
            :field-names="fieldNames"
            show-search
            allow-clear
            @change="handleTreeChange"
        />
        <div class="result">
            <p>选中的值: {{ treeValue }}</p>
            <p>选中的标签: {{ treeLabels }}</p>
        </div>
    </div>
</template>

<script setup>
import { ref } from "vue";

const fieldNames = {
    label: "label",
    value: "value",
    children: "children"
};

// 树结构数据（isLoadData=false）
const treeValue = ref([]);
const treeLabels = ref([]);
const treeLevel = [
    {
        url: "/api/tree/all",
        method: "get"
    }
];

// 树结构数据变化处理
const handleTreeChange = ({ value, selectedOptions, selectedLabels }) => {
    treeLabels.value = selectedLabels;
    console.log(
        "树结构 - 选中的值:",
        value,
        "标签:",
        selectedLabels,
        "选项:",
        selectedOptions
    );
};
</script>

自定义请求函数 ​

自定义请求函数
每个级别可以自定义请求函数，适用于需要特殊处理的场景
<template>
    <div class="demo-section">
        <h3>自定义请求函数</h3>
        <p>每个级别可以自定义请求函数，适用于需要特殊处理的场景</p>
        <WCascader
            v-model:value="customReqValue"
            :levels="customReqLevels"
            placeholder="请选择自定义分类"
            :isLoadData="true"
            :field-names="fieldNames"
            allow-clear
            @change="handleCustomChange"
        />
        <div class="result">
            <p>选中的值: {{ customReqValue }}</p>
            <p>选中的标签: {{ customLabels }}</p>
        </div>
    </div>
</template>

<script setup>
import { ref } from "vue";
import axiosInstance from "../../../../mock/http/request";

const fieldNames = {
    label: "label",
    value: "value",
    children: "children"
};

// 自定义请求函数
const fetchCascader = async (url, method, params) => {
    const config = {
        url,
        method: method || "get",
        [method?.toLowerCase() === "get" ? "params" : "data"]: params
    };
    return await axiosInstance(config);
};

// 自定义 levels 内的 request
const customReqValue = ref([]);
const customLabels = ref([]);
const customReqLevels = [
    {
        url: "/api/custom/level",
        method: "post",
        request: async (url, method, params) => {
            console.log("自定义POST请求 - 第一级", { url, method, params });
            const res = await fetchCascader(url, method, {
                ...params,
                custom: true
            });
            return res.data?.data;
        }
    },
    {
        url: "/api/custom/level2",
        method: "get",
        request: async (url, method, params) => {
            console.log("自定义GET请求 - 第二级", { url, method, params });
            const res = await fetchCascader(url, method, {
                ...params,
                custom: 2
            });
            console.log("自定义GET请求 - 第二级", res);
            return res.data?.data;
        }
    }
];

// 自定义请求变化处理
const handleCustomChange = ({ value, selectedOptions, selectedLabels }) => {
    customLabels.value = selectedLabels;
    console.log(
        "自定义请求 - 选中的值:",
        value,
        "标签:",
        selectedLabels,
        "选项:",
        selectedOptions
    );
};
</script>

API ​

属性 ​

参数说明类型默认值
value(v-model)指定选中项string[][]
levels级联配置，每一级的数据源配置CascaderLevelConfig[][]
options静态数据源，当不使用 levels 时可用CascaderOption[][]
fieldNames自定义字段名object{label: 'label', value: 'value', children: 'children'}
isLoadData是否启用动态加载booleanfalse
autoLoad是否自动加载第一级数据booleantrue
placeholder输入框占位文本string'请选择'
allowClear是否支持清除booleanfalse
showSearch是否支持搜索booleanfalse
disabled是否禁用booleanfalse
size输入框大小'large' | 'middle' | 'small''middle'
expandTrigger次级菜单的展开方式'click' | 'hover''click'
changeOnSelect当此项为 true 时，点选每级菜单选项值都会发生变化booleanfalse
displayRender选择后展示的渲染函数function(labels, selectedOptions)labels => labels.join(' / ')

CascaderLevelConfig ​

参数说明类型默认值
url请求地址string-
method请求方法'get' | 'post' | 'put' | 'delete''get'
params请求参数object{}
isBody是否将参数放在请求体中booleanfalse
request自定义请求函数(url, method, params?) => Promise<any>-

插槽 ​

名称说明参数
suffixIcon自定义的选择框后缀图标-
displayRender自定义选择后展示的内容{ labels, selectedOptions }
optionRender自定义选项的渲染{ option, index }

方法 ​

名称说明参数
reload重新加载数据(level?: number)
getOptions获取当前选项数据(level?: number)
focus获取焦点-
blur失去焦点-

事件 ​

事件名称说明回调参数
change选择完成后的回调{ value, selectedOptions, selectedLabels }
onSuccess数据加载成功的回调{ data, level }
onError数据加载失败的回调{ error, level }
search搜索时的回调(value: string)
popupVisibleChange显示/隐藏浮层的回调(visible: boolean)
