介绍 ^1.3.18 ​

AndForm 表单 配合 vxe-table组件所有的属性事件与方法

使用 ​

sh
npm install vxe-table@next vxe-pc-ui @vxe-ui/plugin-export-xlsx exceljs @vxe-ui/plugin-render-antd
ts
// 完整导入 UI 组件库
import { VxeUI } from "vxe-pc-ui";
import "vxe-pc-ui/lib/style.css";
// 完整导入 表格库
import VxeUITable from "vxe-table";
import "vxe-table/lib/style.css";
// 使用[excel导入和导出](https://vxeui.com/other4/#/plugin-export-xlsx/install)
import VxeUIPluginExportXLSX from "@vxe-ui/plugin-export-xlsx";
import ExcelJS from "exceljs";
// 使用第三方ui库,例如antd
import VxeUIPluginRenderAntd from "@vxe-ui/plugin-render-antd";
import "@vxe-ui/plugin-render-antd/dist/style.css";
const app = createApp(App);
app.use(VxeUITable);
VxeUI.use(VxeUIPluginExportXLSX, {
    ExcelJS
});
VxeUI.use(VxeUIPluginRenderAntd);
app.mount("#app");

多选 ​

通过设置 selection 开启多选，并设置 row-config 中的 keyField，其中 checkboxRowField 设置双向绑定的字段
<template>
    <div class="vp-raw" style="height: 400px">
        <span>选中</span>{{ checkboxRowKey }}
        <a-button @click="setSelectRow(['code2', 'code3'])"
            >设置选中第二、三个</a-button
        >
        <w-vxe-table
            fixed
            url="/table/selection/page"
            :columns="headers"
            :is-page="false"
            selection
            v-model:checkbox-row-key="checkboxRowKey"
            checkboxRowField="code"
            :row-config="{
                keyField: 'code'
            }"
            :checkboxProps="{
                fixed: 'left',
                align: 'center'
            }"
        >
        </w-vxe-table>
    </div>
</template>
<script lang="ts" setup>
import { ref } from "vue";
const checkboxRowKey = ref(["code1", "code5"]);
const headers = ref([
    {
        field: "code",
        title: "编码"
    },
    {
        field: "name",
        title: "姓名"
    },
    {
        field: "age",
        title: "年龄"
    },
    {
        field: "address",
        title: "地址"
    },
    {
        field: "date",
        title: "加入时间"
    }
]);
const setSelectRow = codes => {
    checkboxRowKey.value = codes;
};
</script>

            </w-vxe-table>
        </div>

import { ref } from "vue";
const queryForm = ref({

const headers = ref([

        field: "name",
        title: "姓名",
        search: true,
        form: {
            itemAttrs: {

clipConfig 配置项 ​

参数说明类型默认值
isClip是否启用复制粘贴功能booleanfalse
ignoreColumn全局忽略列（兼容旧版）：不参与区域选择、复制、粘贴和批量清空(column: VxeColumnProps) => boolean;
ignoreCopyColumn仅在复制时忽略；该列在 TSV 中保留空单元格，粘贴和批量清空不受影响(column: VxeColumnProps) => boolean;
ignorePasteColumn禁止写入；当前选区不可写时会从右侧第一个可写列开始，批量清空也会跳过该列(column: VxeColumnProps) => boolean;

ignoreColumn 保持原有的全局禁用语义。需要单独控制方向时使用 ignoreCopyColumn 和 ignorePasteColumn：前者不会泄露该列数据；若当前粘贴起点或框选区域不可写，后者会自动寻找右侧第一个可写列。例如从禁止粘贴的 A 列开始粘贴 x\ty，若 B、C 可写，结果为 B=x、C=y；表格右侧没有可写列时才忽略数据。进入可写列后，选区内后续列仍按原始 TSV 列位置匹配，避免错列。

ts
const clipConfig = {
    isClip: true,
    // 完全排除内部列（兼容旧版语义）
    ignoreColumn: column => column.field === "internalId",
    // 敏感字段可粘贴、不可复制到剪贴板
    ignoreCopyColumn: column => column.field === "sensitiveValue",
    // 公式字段可复制、不可被 Excel 数据覆盖或被批量清空
    ignorePasteColumn: column => column.field === "formula"
};

Delete / Backspace 会批量清空多个单元格选区（包含自定义插槽列）；ignorePasteColumn 命中的不可写列会保持原值。单选 Input 单元格时会保留浏览器原生的逐字符删除行为。

使用 h() 渲染输入组件且绑定字段不同于列的 field 时，可在该列配置 clipboardField，复制、粘贴和删除会读写这个字段。例如：

ts
{
  field: 'displayName',
  clipboardField: 'salesAmountHis',
  slots: {
    default: (params) => h(Input, {
      value: params.row.salesAmountHis,
      'onUpdate:value': (value) => { params.row.salesAmountHis = value }
    })
  }
}
