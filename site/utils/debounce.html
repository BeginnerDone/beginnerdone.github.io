Debounce 防抖 ​

主要用于函数防抖处理，优化高频事件触发

方法 ​

debounce ​

创建一个防抖函数，在指定时间内多次调用只执行最后一次

ts
import { debounce } from '@wlink/utils'

// 基本用法
const debouncedFn = debounce(() => {
    console.log('执行了')
}, 300)

// 多次快速调用，只会在最后一次调用后300ms执行
debouncedFn()
debouncedFn()
debouncedFn() // 只有这次会真正执行

参数 ​

参数类型描述
funcFunction要防抖的函数
waitnumber延迟时间（毫秒）
optionsDebounceOptions配置选项

配置选项 (DebounceOptions) ​

参数类型默认值描述
immediatebooleanfalse是否立即执行（第一次调用时）
maxWaitnumber-最大等待时间，超过此时间强制执行

返回值方法 ​

防抖函数还提供了额外的控制方法：

方法描述
cancel取消延迟执行
flush立即执行并取消延迟

使用示例 ​

基本防抖 ​

ts
import { debounce } from '@wlink/utils'

// 搜索输入防抖
const searchDebounced = debounce((keyword: string) => {
    console.log('搜索:', keyword)
    // 执行搜索逻辑
}, 500)

// 用户快速输入时，只有停止输入500ms后才会执行搜索
searchDebounced('a')
searchDebounced('ab')
searchDebounced('abc') // 只有这次会执行

立即执行模式 ​

ts
// 第一次调用立即执行，后续调用防抖
const immediateDebounced = debounce(() => {
    console.log('立即执行')
}, 1000, { immediate: true })

immediateDebounced() // 立即执行
immediateDebounced() // 被防抖
immediateDebounced() // 被防抖

最大等待时间 ​

ts
// 即使一直有新的调用，也会在最大等待时间后强制执行
const maxWaitDebounced = debounce(() => {
    console.log('强制执行')
}, 500, { maxWait: 2000 })

// 即使每400ms调用一次，也会在2000ms后强制执行
setInterval(() => {
    maxWaitDebounced()
}, 400)

控制方法使用 ​

ts
const controlDebounced = debounce(() => {
    console.log('执行了')
}, 1000)

controlDebounced()

// 取消执行
controlDebounced.cancel()

// 立即执行
controlDebounced.flush()

实际应用场景 ​

ts
// 1. 窗口resize事件
const handleResize = debounce(() => {
    console.log('窗口大小改变')
    // 重新计算布局
}, 250)

window.addEventListener('resize', handleResize)

// 2. 表单验证
const validateInput = debounce((value: string) => {
    // 执行验证逻辑
    console.log('验证:', value)
}, 300)

// 3. API请求防抖
const fetchData = debounce(async (params: any) => {
    try {
        const response = await fetch('/api/data', {
            method: 'POST',
            body: JSON.stringify(params)
        })
        const data = await response.json()
        console.log('数据:', data)
    } catch (error) {
        console.error('请求失败:', error)
    }
}, 500)

// 4. 按钮点击防抖（防止重复提交）
const submitForm = debounce(() => {
    console.log('提交表单')
    // 提交逻辑
}, 1000, { immediate: true })

注意事项 ​

  1. 内存管理：防抖函数会保持对原函数和参数的引用，注意避免内存泄漏
  2. this绑定：防抖函数会正确绑定原函数的this上下文
  3. 返回值：只有实际执行的调用才会返回函数结果
  4. 类型安全：完全保持原函数的类型签名
