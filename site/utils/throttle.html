Throttle 节流函数 ​

高性能的节流函数实现，用于限制函数的执行频率

功能特点 ​

  • 高性能：优化的算法实现，支持高频调用场景
  • 完整配置：支持 leading、trailing、maxWait 等多种配置选项
  • 类型安全：完整的 TypeScript 类型支持
  • 方法丰富：提供 cancel、flush、pending 等控制方法
  • 兼容性强：支持同步和异步函数

方法列表 ​

方法名描述参数返回值
throttle创建节流函数（完整版）func, wait, options?ThrottledFunction
simpleThrottle创建节流函数（简化版）func, waitFunction

基础用法 ​

throttle - 完整版节流函数 ​

ts
import { throttle } from '@wlink/utils'

// 基础用法
const handleScroll = throttle(() => {
    console.log('滚动事件处理')
}, 100)

// 绑定事件
window.addEventListener('scroll', handleScroll)

// 移除事件时记得取消
window.removeEventListener('scroll', handleScroll)
handleScroll.cancel()

simpleThrottle - 简化版节流函数 ​

ts
import { simpleThrottle } from '@wlink/utils'

// 简单的节流函数，性能更好但功能较少
const handleResize = simpleThrottle(() => {
    console.log('窗口大小改变')
}, 200)

window.addEventListener('resize', handleResize)

配置选项 ​

ThrottleOptions 接口 ​

ts
interface ThrottleOptions {
    leading?: boolean;   // 是否在第一次调用时立即执行，默认 true
    trailing?: boolean;  // 是否在最后一次调用后延迟执行，默认 true
    maxWait?: number;    // 最大等待时间，超过此时间强制执行
}

leading 选项 ​

ts
// 立即执行（默认行为）
const throttledFn1 = throttle(fn, 1000, { leading: true })

// 不立即执行，等待间隔后执行
const throttledFn2 = throttle(fn, 1000, { leading: false })

// 示例：搜索输入框
const handleSearch = throttle((query: string) => {
    console.log('搜索:', query)
}, 500, { leading: false }) // 用户停止输入后才搜索

trailing 选项 ​

ts
// 在最后一次调用后延迟执行（默认行为）
const throttledFn1 = throttle(fn, 1000, { trailing: true })

// 不在最后一次调用后执行
const throttledFn2 = throttle(fn, 1000, { trailing: false })

// 示例：按钮点击
const handleClick = throttle(() => {
    console.log('按钮被点击')
}, 1000, { trailing: false }) // 只在第一次点击时执行

maxWait 选项 ​

ts
// 设置最大等待时间
const throttledFn = throttle(fn, 1000, { maxWait: 3000 })

// 示例：数据保存
const autoSave = throttle((data: any) => {
    console.log('自动保存数据')
}, 2000, { 
    maxWait: 10000 // 最多等待 10 秒就强制保存
})

控制方法 ​

cancel() - 取消执行 ​

ts
const throttledFn = throttle(() => {
    console.log('执行了')
}, 1000)

throttledFn() // 立即执行
throttledFn() // 等待执行

// 取消等待中的执行
throttledFn.cancel()

// 常用场景：组件卸载时取消
const cleanup = () => {
    throttledFn.cancel()
}

flush() - 立即执行 ​

ts
const throttledFn = throttle(() => {
    console.log('执行了')
    return 'result'
}, 1000)

throttledFn() // 立即执行
throttledFn() // 等待执行

// 立即执行等待中的调用
const result = throttledFn.flush()
console.log(result) // 'result'

// 常用场景：页面卸载前强制执行
window.addEventListener('beforeunload', () => {
    autoSave.flush() // 强制保存数据
})

pending() - 检查状态 ​

ts
const throttledFn = throttle(() => {
    console.log('执行了')
}, 1000)

console.log(throttledFn.pending()) // false

throttledFn() // 立即执行
throttledFn() // 等待执行

console.log(throttledFn.pending()) // true

// 1 秒后
setTimeout(() => {
    console.log(throttledFn.pending()) // false
}, 1100)

实际应用场景 ​

滚动事件优化 ​

ts
import { throttle } from '@wlink/utils'

// 滚动位置监听
const handleScroll = throttle(() => {
    const scrollTop = window.pageYOffset
    const windowHeight = window.innerHeight
    const documentHeight = document.documentElement.scrollHeight
    
    // 检查是否滚动到底部
    if (scrollTop + windowHeight >= documentHeight - 100) {
        loadMoreData()
    }
    
    // 更新滚动进度
    updateScrollProgress(scrollTop / (documentHeight - windowHeight))
}, 100)

window.addEventListener('scroll', handleScroll)

// 组件卸载时清理
const cleanup = () => {
    window.removeEventListener('scroll', handleScroll)
    handleScroll.cancel()
}

搜索输入优化 ​

ts
import { throttle } from '@wlink/utils'

// 搜索建议
const handleSearchInput = throttle(async (query: string) => {
    if (query.length < 2) return
    
    try {
        const suggestions = await searchAPI(query)
        updateSuggestions(suggestions)
    } catch (error) {
        console.error('搜索失败:', error)
    }
}, 300, { leading: false })

// 绑定输入事件
const searchInput = document.getElementById('search') as HTMLInputElement
searchInput.addEventListener('input', (e) => {
    handleSearchInput((e.target as HTMLInputElement).value)
})

import { throttle } from '@wlink/utils'

// 响应式布局调整
const handleResize = throttle(() => {

按钮防重复点击 ​

ts
import { throttle } from '@wlink/utils'

// 提交按钮
const handleSubmit = throttle(async (formData: any) => {
    try {
        setLoading(true)
        await submitForm(formData)
        showMessage('提交成功')
    } catch (error) {
        showMessage('提交失败', 'error')
    } finally {
        setLoading(false)
    }
}, 2000, {
    leading: true,
    trailing: false // 只在第一次点击时执行
})

// 绑定按钮点击
const submitButton = document.getElementById('submit')
submitButton?.addEventListener('click', () => {
    const formData = getFormData()
    handleSubmit(formData)
})

性能对比 ​

throttle vs simpleThrottle ​

ts
// 完整版 - 功能丰富但稍重
const fullThrottle = throttle(fn, 100, {
    leading: true,
    trailing: true,
    maxWait: 500
})

// 简化版 - 性能更好但功能简单
const simpleThrottle = simpleThrottle(fn, 100)

// 性能测试
console.time('fullThrottle')
for (let i = 0; i < 10000; i++) {
    fullThrottle()
}
console.timeEnd('fullThrottle')

console.time('simpleThrottle')
for (let i = 0; i < 10000; i++) {
    simpleThrottle()
}
console.timeEnd('simpleThrottle')

选择建议 ​

  • 使用 throttle：需要精确控制、取消/立即执行功能、复杂配置
  • 使用 simpleThrottle：简单场景、追求极致性能、不需要额外功能

与 debounce 的区别 ​

特性throttle（节流）debounce（防抖）
执行时机固定时间间隔内最多执行一次停止触发后延迟执行
适用场景滚动、拖拽、实时搜索输入验证、按钮防重复点击
执行频率有规律的执行不规律的执行
响应性更好的实时响应更好的性能优化
ts
// 节流：每 100ms 最多执行一次
const throttled = throttle(fn, 100)

// 防抖：停止调用 100ms 后执行
const debounced = debounce(fn, 100)

// 滚动事件 - 使用节流
window.addEventListener('scroll', throttle(handleScroll, 100))

// 搜索输入 - 使用防抖
input.addEventListener('input', debounce(handleSearch, 300))

注意事项 ​

  1. 内存管理：记得在组件卸载时调用 cancel() 方法
  2. 异步函数：支持异步函数，但返回值是 Promise
  3. 参数传递：最后一次调用的参数会被传递给实际执行的函数
  4. 上下文绑定：正确处理 this 上下文
  5. 错误处理：函数内部的错误需要自行处理
ts
// 正确的清理方式
const throttledFn = throttle(fn, 100)

// 组件卸载时
const cleanup = () => {
    throttledFn.cancel() // 取消待执行的调用
}

// 错误处理
const safeThrottledFn = throttle(async (data) => {
    try {
        await riskyOperation(data)
    } catch (error) {
        console.error('操作失败:', error)
        // 处理错误
    }
}, 1000)
