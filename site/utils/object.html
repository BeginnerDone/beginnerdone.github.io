Object 对象操作 ​

主要用于对象的深度操作和处理

方法 ​

cloneDeep ​

深度克隆对象，支持循环引用和各种复杂类型

ts
import { cloneDeep } from '@wlink/utils'

const original = {
    name: 'test',
    nested: {
        value: 42,
        items: [1, 2, 3]
    },
    date: new Date(),
    regex: /test/g
}

const cloned = cloneDeep(original)
// cloned 是 original 的完全独立副本
cloned.nested.value = 100
console.log(original.nested.value) // 42 (原对象未被修改)

支持的数据类型 ​

类型支持情况说明
基本类型✅string, number, boolean, null, undefined
普通对象✅包括嵌套对象
数组✅包括多维数组
Date✅创建新的Date实例
RegExp✅保持原有的flags
Function✅直接返回原函数引用
Error✅创建新的Error实例
Map✅深度克隆键值对
Set✅深度克隆集合元素
ArrayBuffer✅创建新的缓冲区
TypedArray✅Int8Array, Uint8Array等
DataView✅创建新的DataView实例
Symbol属性✅包括Symbol键的属性
循环引用✅使用WeakMap避免无限递归
原型链✅保持原有的原型链

使用示例 ​

基本对象克隆 ​

ts
import { cloneDeep } from '@wlink/utils'

const user = {
    id: 1,
    name: 'John',
    profile: {
        age: 30,
        hobbies: ['reading', 'coding']
    }
}

const clonedUser = cloneDeep(user)
clonedUser.profile.age = 31
clonedUser.profile.hobbies.push('gaming')

console.log(user.profile.age)        // 30 (原对象未变)
console.log(user.profile.hobbies)    // ['reading', 'coding'] (原数组未变)

复杂类型克隆 ​

ts
const complex = {
    date: new Date('2023-01-01'),
    regex: /test/gi,
    map: new Map([['key1', 'value1'], ['key2', { nested: true }]]),
    set: new Set([1, 2, { obj: 'value' }]),
    buffer: new ArrayBuffer(8),
    error: new Error('test error')
}

const clonedComplex = cloneDeep(complex)

// 验证是否为独立副本
console.log(clonedComplex.date !== complex.date)           // true
console.log(clonedComplex.regex !== complex.regex)         // true
console.log(clonedComplex.map !== complex.map)             // true
console.log(clonedComplex.set !== complex.set)             // true
console.log(clonedComplex.buffer !== complex.buffer)       // true
console.log(clonedComplex.error !== complex.error)         // true

循环引用处理 ​

ts
const obj: any = {
    name: 'circular'
}
obj.self = obj  // 创建循环引用

const clonedObj = cloneDeep(obj)
console.log(clonedObj.self === clonedObj)  // true (保持循环引用结构)
console.log(clonedObj !== obj)             // true (但是不同的对象)

Symbol属性克隆 ​

ts
const sym1 = Symbol('key1')
const sym2 = Symbol('key2')

const objWithSymbols = {
    normalProp: 'value',
    [sym1]: 'symbol value 1',
    [sym2]: { nested: 'symbol value 2' }
}

const cloned = cloneDeep(objWithSymbols)

// Symbol属性也被正确克隆
console.log(cloned[sym1])  // 'symbol value 1'
console.log(cloned[sym2])  // { nested: 'symbol value 2' }

自定义类实例克隆 ​

ts
class CustomClass {
    constructor(public value: number) {}
    
    getValue() {
        return this.value
    }
}

const instance = new CustomClass(42)
const clonedInstance = cloneDeep(instance)

// 保持原型链
console.log(clonedInstance instanceof CustomClass)  // true
console.log(clonedInstance.getValue())               // 42
console.log(clonedInstance !== instance)             // true

TypedArray克隆 ​

ts
const uint8Array = new Uint8Array([1, 2, 3, 4])
const int32Array = new Int32Array([100, 200, 300])

const obj = {
    uint8: uint8Array,
    int32: int32Array
}

const cloned = cloneDeep(obj)

// TypedArray被正确克隆
console.log(cloned.uint8 instanceof Uint8Array)     // true
console.log(cloned.int32 instanceof Int32Array)     // true
console.log(cloned.uint8 !== obj.uint8)             // true
console.log(Array.from(cloned.uint8))                // [1, 2, 3, 4]

性能考虑 ​

  1. 大对象克隆：对于非常大的对象，克隆操作可能比较耗时
  2. 循环引用检测：使用WeakMap进行循环引用检测，性能优于传统方案
  3. 内存使用：克隆会创建完全独立的副本，内存使用量会翻倍

注意事项 ​

  1. 函数克隆：函数直接返回原引用，不会创建新的函数副本
  2. DOM节点：不支持DOM节点的克隆
  3. WeakMap/WeakSet：由于其特殊性质，无法被克隆
  4. 原生对象：如window、document等原生对象可能无法正确克隆
